# javascript-calculator-precourse

## 기능 목록
  [ ] 덧셈 계산기 구현
  [ ] 문자열 입력 받기
      
  [ ] 쉼표, 콜론 기준으로 숫자 구별하기 
  [ ] 커스텀 구분자(//와 \n 사이에 있는 특수문자) 지정하기
  [ ] 커스텀 구분자 기준으로 숫자 구별하기
  [ ] 결과값 출력하기
      
  [ ] error 메세지와 error 발생 시키기
    - [ ] 음수 
    - [ ] 구분자와 양수가 아닌 이외의 값
    - [ ] 커스텀 구분자가 문자가 아닌 경우
  [ ] 어플리케이션 종료

## 고려사항
  [ ] 구분자와 양수로 구성된 문자열
  [ ] 프로그램 종료 시 process.exit()를 호출하지 않음
  [ ] 빈 문자열 입력시 0
